Excel File Format

Arrange your Excel columns in the following order:

Column 1: First Name
Column 2: Last Name
Column 3: Email
Column 4: Phone
Column 5: Department
Column 6: Salary
Column 7: Joining Date

Important:
  • Use the first row for column headings.
  • Enter employee records starting from the second row.
  • Use existing department names such as IT, HR or DEV.
  • Use a valid email address for each employee.
  • Enter joining dates in yyyy-MM-dd format or as Excel dates.
  • Upload only .xlsx files.
